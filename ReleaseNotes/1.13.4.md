# Elapse Recorder 1.13.4

This release reduces periodic input stalls while background capture is active, especially in latency-sensitive drawing applications.

## Performance

- Cache unchanged Stage Manager window geometry instead of sending synchronous Accessibility requests to the captured application every interval.
- Run window capture, image persistence, and HEVC segment work at background priority.
- Capture an application's windows serially by default to avoid bursty WindowServer contention.
